# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be respectful, assume good intent, and focus on what's best for the community. Harassment of any kind is not tolerated.

To report unacceptable behavior, open a private [security advisory](https://github.com/seaver-choy/spotlight-studio/security/advisories/new) or contact the maintainer through their GitHub profile. All reports are reviewed and kept confidential.
